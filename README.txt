SOLO SYSTEM — MONARCH / THUNDER UPDATE

WHAT CHANGED
- Near-black interface with travelling energy borders, irregular lightning flashes, scan effects and level-reactive aura.
- The aura gradually shifts from blue toward violet as you approach Level 60, then into brighter purple/pink at higher levels.
- Synthesized sci-fi system sounds for notifications, quest claims, level-ups and penalty alerts. Audio is generated locally by the browser; enable/disable it in Save / Settings. Browsers may require a first click before audio can play.
- Daily Body Training accordion: 3 km walk/run target, push-ups, sit-ups/crunches, plank, bodyweight squats, plus selectable workout/mobility/low-energy options.
- Countdown to local midnight. If the baseline body protocol remains incomplete at the next day rollover, a randomized 10–35 XP penalty is applied (never below 0 XP), and other tabs remain locked until a safe penalty protocol is acknowledged.
- Existing quests, stats, skill trees, bosses, achievements, journal, and backup/import features are retained.

INSTALL / OPEN
1. Extract this ZIP.
2. Open the solo_system_fixed folder.
3. Double-click index.html to use it in Chrome or Edge.
4. To install it as a home-screen app on phones, host the folder on an HTTPS website (for example, GitHub Pages), then use the browser's Install app / Add to Home Screen option.

NOTES
- Progress is saved locally in this browser on this device. Export a backup before clearing browser data or moving devices.
- Sound effects are original synthesized tones, not ripped audio from the anime.
- Training is a motivational game layer, not medical advice. Scale tasks to ability; walking counts for the distance target. Do not push through pain, illness, unsafe weather or unsafe surroundings. Use the low-energy option or rest when needed.
- Penalty check happens when the app detects a new local calendar day. Keep the device clock set correctly.
